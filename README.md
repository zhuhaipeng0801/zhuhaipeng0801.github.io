# Built Environment Vision and Cognition Group

Bilingual academic website of the BEVC research group.

## Hosting

Target repository: `zhuhaipeng0801/zhuhaipeng0801.github.io`.
Publish the `main` branch root with GitHub Pages. `.nojekyll` preserves the static files without Jekyll processing.

## Local maintenance

Edit the original website public directory in the local ResearchOS workspace, preview the changes, then synchronize approved files into this repository before committing and pushing.

Website text, photographs, figures, papers and videos retain their respective rights. This repository does not grant a blanket reuse license.
